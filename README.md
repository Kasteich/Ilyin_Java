# Ilyin_Java (Java 11)

## Требования
- Java 11

## Что сделано
1) Программа принимает два целых числа `a` и `b` (ввод одной строкой через пробел):
   - сравнивает их и выводит: `a > b`, `a < b` или `a = b`
   - выводит результаты операций: сложение, вычитание, умножение, деление (деление на ноль обработано)

2) Программа принимает две строки `a` и `b` и сравнивает их:
   - выводит: `Строки идентичны` или `Строки неидентичны`

3) Дан массив `[1..10]`:
   - выводит в консоль все чётные числа
